# Blog Robson Lopes

Blog sobre **tecnologia, inteligência artificial, automação e processos**, criado para documentar aprendizados, projetos e aplicações práticas.

## Propósito

Compartilhar conteúdos que conectam desenvolvimento de software e tecnologia a problemas reais de negócios, acompanhando a construção da minha carreira e dos projetos que desenvolvo.

> **Tecnologia para negócios funcionarem melhor.**

## Conteúdos

- Desenvolvimento de software
- Inteligência artificial aplicada
- Automação e integrações
- Organização e melhoria de processos
- Bastidores, aprendizados e estudos de caso

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- MDX
- Tailwind CSS 4

## Executar localmente

Requisitos: Node.js 22 ou superior.

```bash
npm install
npm run dev
```

O blog estará disponível em `http://localhost:3000`.

Para verificar e gerar a versão de produção:

```bash
npm run lint
npm run build
```

## Publicação

O blog é exportado de forma estática e publicado automaticamente no GitHub Pages por meio do workflow [deploy-pages.yml](.github/workflows/deploy-pages.yml) a cada atualização da branch `main`.

Acesse: [blog.robsonlopes.tec.br](https://blog.robsonlopes.tec.br)
